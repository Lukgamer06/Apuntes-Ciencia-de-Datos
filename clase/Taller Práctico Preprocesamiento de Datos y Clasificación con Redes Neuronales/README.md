# Taller práctico de preprocesamiento y clasificación con redes neuronales

Este directorio reúne un ejercicio práctico de ciencia de datos centrado en el preprocesamiento de datos y la construcción de un modelo de clasificación basado en redes neuronales.

## Contenido

- Datos crudos en formato CSV y JSON.
- Datos procesados ya normalizados o transformados.
- Notebook principal con el flujo completo de análisis.
- Archivos de salida intermedios y resultados del proceso.

## Objetivo

El proyecto busca aplicar una pipeline completa de ciencia de datos, que incluye:

- limpieza y preparación de datos
- transformación de variables
- normalización o estandarización
- entrenamiento de una red neuronal para clasificación
- evaluación del modelo y análisis de resultados

## Archivos principales

- `datos.csv`: dataset original.
- `datos_procesados.csv` y `datos_procesados.json`: versiones transformadas del dataset.
- `Procesamiento_Datos_Clasificacion.ipynb`: cuaderno con el desarrollo principal.
- `Prueba.ipynb`: pruebas o experimentos adicionales.

## Enfoque metodológico

El taller está orientado a mostrar el ciclo completo de un problema de clasificación:

1. cargar y explorar los datos
2. preparar variables para el modelo
3. aplicar técnicas de preprocesamiento
4. entrenar una red neuronal
5. comparar resultados y explicar el comportamiento del modelo

## Tecnologías

- Python
- Pandas
- NumPy
- scikit-learn
- TensorFlow / Keras
- Jupyter Notebook

## Resultado esperado

Se busca dejar una base práctica clara para resolver tareas de clasificación con redes neuronales a partir de datos tabulares, enfatizando la importancia del preprocesamiento en la calidad del modelo final.
