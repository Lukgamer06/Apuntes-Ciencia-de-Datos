# Imágenes

Este directorio reúne ejercicios y cuadernos centrados en procesamiento digital de imágenes y redes neuronales convolucionales (CNN).

## Contenido

- Procesamiento digital de imágenes.
- Entrenamiento y evaluación de CNN.
- Transfer learning con modelos preentrenados.
- Aplicaciones de visión por computador.

## Objetivos del material

Los cuadernos incluidos están orientados a comprender cómo las redes convolucionales aprenden patrones visuales a partir de imágenes y cómo pueden reutilizarse modelos ya entrenados para tareas específicas con menos datos y mejor rendimiento.

## Temas principales

- filtros y transformaciones de imágenes
- extracción de características visuales
- arquitecturas CNN
- transfer learning
- clasificación de imágenes
- ajuste fino de modelos preentrenados

## Tecnologías

- Python
- Jupyter Notebook
- OpenCV
- TensorFlow / Keras
- NumPy
- Matplotlib

## Uso sugerido

1. Revisar el cuaderno de procesamiento digital de imágenes.
2. Continuar con el cuaderno de redes convolucionales.
3. Estudiar el caso de transferencia de aprendizaje.
4. Ejecutar cada bloque para observar cómo cambian las características aprendidas.

## Resultado esperado

Se busca desarrollar una base práctica para resolver tareas de clasificación y análisis visual usando redes neuronales convolucionales, desde conceptos básicos hasta enfoques avanzados de transferencia de aprendizaje.
