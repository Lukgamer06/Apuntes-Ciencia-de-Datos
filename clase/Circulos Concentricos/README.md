# Círculos concéntricos

Este directorio contiene el cuaderno y el material relacionado con un problema clásico de clasificación no lineal: distinguir puntos según si pertenecen a círculos concéntricos.

## ¿Qué incluye?

- Notebook de entrenamiento y visualización del problema.
- Experimentos con redes neuronales densas para resolver la clasificación.
- Exploración de la separación entre regiones internas y externas.

## Objetivo

El objetivo principal es entrenar una red neuronal para separar correctamente las regiones de un conjunto de datos con forma circular, lo que permite practicar conceptos como:

- clasificación binaria
- representación no lineal de datos
- redes neuronales densas
- visualización de decisiones del modelo

## Uso sugerido

1. Abrir el cuaderno principal en este directorio.
2. Revisar el preprocesamiento y la preparación de datos.
3. Ejecutar las celdas para entrenar la red.
4. Evaluar la frontera de decisión y la precisión del modelo.

## Tecnologías

- Python
- Jupyter Notebook
- NumPy
- Matplotlib
- TensorFlow / Keras o scikit-learn (según la implementación del cuaderno)

## Resultados esperados

Se espera observar cómo una red neuronal densa puede aprender patrones no lineales y separar regiones circulares con mejor desempeño que un clasificador lineal.
