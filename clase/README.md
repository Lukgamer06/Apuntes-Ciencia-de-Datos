# Ciencia de Datos

Este repositorio reúne varios proyectos, cuadernos y ejercicios de ciencia de datos, inteligencia artificial y visión por computador desarrollados durante la práctica del curso.

## Objetivo

La idea principal es consolidar material de aprendizaje y experimentación para temas como:

- aprendizaje automático
- redes neuronales
- clasificación y regresión
- preprocesamiento de datos
- visión artificial y detección de objetos
- transferencia de aprendizaje
- despliegue de modelos y prototipos

## Estructura del proyecto

- [Apuntes Ciencia de Datos](Apuntes%20Ciencia%20de%20Datos/): apuntes, ejercicios y cuadernos del curso.
- [Circulos Concentricos](Circulos%20Concentricos/): proyecto sobre clasificación con círculos concéntricos.
- [Deployment-Mobile-Yolo-main](Deployment-Mobile-Yolo-main/): despliegue móvil y backend con YOLO.
- [Huevos](Huevos/): detección y clasificación de huevos con visión artificial.
- [Imagenes](Imagenes/): notebooks de procesamiento de imágenes y CNN.
- [Placas](Placas/): detección de matrículas y backend de inferencia.
- [Prendas](Prendas/): clasificación de prendas con redes neuronales.
- [Redes densas](Redes%20densas/): redes neuronales densas y aplicaciones de regresión/clasificación.
- [Taller Práctico Preprocesamiento de Datos y Clasificación con Redes Neuronales](Taller%20Pr%C3%A1ctico%20Preprocesamiento%20de%20Datos%20y%20Clasificaci%C3%B3n%20con%20Redes%20Neuronales/): taller práctico de preprocesamiento y modelos neuronales.

## Requisitos generales

Se recomienda usar un entorno virtual de Python y trabajar con dependencias específicas por carpeta. En cada proyecto puede haber un `requirements.txt` o instrucciones particulares.

```bash
git clone <url-del-repositorio>
cd clase
python -m venv .venv
source .venv/bin/activate  # Linux / WSL
# o .venv\Scripts\activate en Windows
```

## Buenas prácticas

- No subir artefactos pesados como modelos entrenados, datasets grandes o nodos de dependencias.
- Mantener cada proyecto con su propio README y requisitos si corresponde.
- Usar variables de entorno para claves, credenciales y configuraciones sensibles.
- Revisar el archivo `.gitignore` antes de hacer commits importantes.
