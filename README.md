# Apuntes de Ciencia de Datos

Este repositorio contiene apuntes organizados, ejemplos prácticos y material de estudio relacionado con Ciencia de Datos. Su propósito es servir como referencia clara y progresiva para estudiantes y desarrolladores que buscan comprender los fundamentos y las aplicaciones prácticas del análisis de datos y el machine learning.

## Objetivo del repositorio

- Consolidar conceptos fundamentales de estadística, probabilidad y álgebra lineal.
- Documentar herramientas esenciales del ecosistema Python para análisis de datos.
- Explicar técnicas de preprocesamiento y preparación de datos.
- Presentar modelos clásicos de machine learning con teoría y ejemplos.
- Proveer guías para estructurar proyectos reales de Ciencia de Datos.

## Tecnologías utilizadas

- Python 3.x  
- NumPy  
- Pandas  
- Scikit-learn  
- Matplotlib  
- Seaborn  
- Jupyter Notebook
